Проблема известная: официальные серверы Arduino действительно блокируют запросы из России, возвращая ошибку **403 Forbidden**.

К счастью, эту проблему можно решить, перенаправив `arduino-cli` на использование **зеркал (mirror-репозиториев)**. Ниже я опишу два способа, которые помогут вам обойти блокировку.

### Способ 1: Настройка зеркала для всех плат (универсальный)

Этот способ подходит для загрузки ядер любых плат, включая стандартные Arduino.

Для этого нужно создать конфигурационный файл `arduino-cli.yaml`, который будет указывать `arduino-cli` на альтернативный источник.

1.  **Создайте конфигурационный файл** в вашей домашней директории:
    ```bash
    micro ~/.arduino15/arduino-cli.yaml
    ```

2.  **Вставьте** в него следующий текст. Он перенаправит загрузку индексов и самих пакетов на зеркало, расположенное в Китае.
    ```yaml
    board_manager:
      additional_urls:
        - https://mirrors.tuna.tsinghua.edu.cn/arduino/package_index.json
    ```
    > **Важно:** Это зеркало (Tsinghua University) является одним из самых надежных публичных зеркал. Однако оно может не всегда содержать самые свежие обновления, но для работы с основной линейкой плат этого достаточно.

3.  **Обновите индексы** с новыми настройками:
    ```bash
    arduino-cli core update-index
    ```

4.  **Установите ядро** для вашей платы (например, для Arduino Uno):
    ```bash
    arduino-cli core install arduino:avr
    ```

После этих шагов `arduino-cli` будет работать через зеркало, и блокировка больше не должна мешать.

---

### Способ 2: Настройка зеркала для конкретной платы (ESP32 и другие)

Если вы работаете с конкретной платой, например, ESP32, у многих производителей есть собственные официальные зеркала.

Например, для **ESP32** можно использовать зеркало от Espressif:
```bash
arduino-cli config set board_manager.additional_urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

Или даже специализированное китайское зеркало для ESP32:
```bash
arduino-cli config set board_manager.additional_urls https://jihulab.com/esp-mirror/espressif/arduino-esp32/-/raw/gh-pages/package_esp32_index_cn.json
```

---

### Способ 3: Ручная установка (крайний случай)

Если зеркала не работают, можно скачать необходимые файлы вручную с помощью другого компьютера или через VPN и перенести их на вашу машину. Это сложнее и требует понимания структуры файлов `arduino-cli`, но может быть единственным выходом, если блокировка затронет и зеркала.

---

### Проверка решения

После выполнения любого из способов проверьте, что плата теперь определяется:
```bash
arduino-cli board list
```

Если вывод показывает вашу плату (например, `/dev/ttyACM0`), значит, проблема решена, и ваша программа Hex Loader сможет её найти.
